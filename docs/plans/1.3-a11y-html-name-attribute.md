## Purpose

- **🔷** OLLMchat needs AT-SPI-shaped object attributes matching **WebKitGTK**:
  - `"name"` → HTML form **`name=`** (primary fill key)
  - `"id"` → HTML **`id=`**
  - `"tag"` → HTML tag when available
- **🔷** Surface those on `AndroidAtspi.Accessible.get_attributes()` so `OLLMwebkit.A11yParse` can build `(^fill:q)` from `attrs.get("name")`.
- **🚫** Do **not** implement OLLMchat dump markdown or `fill` argument redesign here.
- **🚫** Do **not** use page JS / `evaluate_javascript` / DOM scrape.
- **🔷** Prefer `AccessibilityNodeInfo` for actions; HTML attrs from Chromium **`WebView.onProvideVirtualStructure`** (AssistStructure / password-manager path) — same data Windows reads via IA2, still engine a11y.

---

## Why this repo

Stock **WebKitGTK** exposes `"id"` + `"tag"` but **not** HTML `"name"`. This library’s walk node had accessible `name` / role / value only; facade only set `computed-role`.

---

## Target contract (locked for OLLMchat)

After walk → facade build, for a node backed by `<input name="q" id="search" …>`:

```
get_attributes() → { "name": "q", "id": "search", "tag": "input", "computed-role": "…" }
```

- **🔷** Keys exactly `"name"`, `"id"`, `"tag"` (WebKitGTK spelling).
- **🔷** Omit empty keys.
- **🔷** `get_name()` stays the accessible label — **not** HTML `name=`.

## Phases

### Phase 0 — ✔️ Spike: NodeInfo vs AssistStructure

- **✔️** NodeInfo / extras: **no** HTML `name=` (only `viewIdResourceName` → id, `chromeRole`).
- **✔️** AssistStructure side door: `onProvideVirtualStructure` → `HtmlInfo` has `tag=input` + `name=email` / `name=q` (async snapshot; wait for `asyncCommit`).
- **✔️** Merge onto editable walk rows (document order when virtual ids missing).

| Source | HTML `name=` | HTML `id=` | HTML tag |
|--------|--------------|------------|----------|
| `AccessibilityNodeInfo` extras | no | via `viewIdResourceName` | no (`chromeRole` only) |
| `ViewStructure` HtmlInfo | **yes** (`name` attr) | often empty in HtmlInfo; use viewId | **yes** |

### Phase 1 — ✔️ Extend Java Node + JNI / C struct

- **✔️** `Node.htmlName` / `htmlId` / `htmlTag` + `CaptureViewStructure`
- **✔️** `wka_a11y_node` + foreach + Vala `WalkRow`

### Phase 2 — ✔️ AndroidAtspi attributes

- **✔️** `set_attr("name"|"id"|"tag", …)` when non-empty; keep `computed-role`

## LLM notes

- Match WebKitGTK attr **key strings** (`name`, `id`, `tag`).
- Java `Node.name` is accessible name — use `htmlName` for HTML `name=`.
- `onProvideVirtualStructure` is **async** — `walkAsync` waits for commit (3s timeout).
- `<input>`-oriented (Chromium `kHtmlInputName`); textarea/select may lack `name` in HtmlInfo.
- Do not pretend `id` is `name`.
