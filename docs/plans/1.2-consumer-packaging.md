## Purpose

- **🔷** Stop shipping only example executables — ship an installable / linkable library so OLLMchat (and other apps) can `dependency('webkitgtk-android-1')`.
- **🔷** Mirror webview2-gtk consumer shape: pkg-config name + VAPI + shared lib; Android adds **Java host classes** in the same APK.
- **🔷** Keep a11y host entry points **off** `WebView` (same as Windows: host / facade, not WebKit-shaped widget methods).
- **🚫** Do not wire OLLMchat `Browser` / tool registration here — that is **5.0.2**.

---

## Locked decisions

### Meson product

- **🔷** Default Android configure (neither hello nor browser) builds the **library**.
- **🔷** `-Dandroid_browser=true` → library + browser example that **links** it.
- **🔷** `-Dandroid_hello=true` → hello exe only (**skip** library — hello Pixiewood has no libsoup).
- **🔷** pkg-config / soname: **`webkitgtk-android-1`** / `libwebkitgtk-android-1.so`.
- **🔷** `meson.override_dependency('webkitgtk-android-1', …)` so a Meson subproject works without a prefix install.

### VAPI (one file)

- **🔷** Single checked-in **`vapi/webkitgtk-android-1.vapi`** (like `webview2gtk-1.vapi`).
- **🔷** Contents: `WebKitGtkAndroid.*` widget API **plus** file-scope `wka_host_a11y_*` (ensure / walk / invoke / set_value / focus).
- **🚫** No second `*-host.vapi`.
- **🚫** No `a11y_*` methods on `WebView` — Meson-generated library VAPI also must not grow those wrappers.
- **ℹ️** Meson still generates a build-tree VAPI from Vala sources for in-tree linking; keep the checked-in file aligned for prefix / wrap consumers.
- **ℹ️** Browser demo: `examples/browser/host-a11y.vala` redeclares host entry points locally (generated lib VAPI omits bare `extern`s).
- **✔️** **Valadoc** on Linux: `meson setup build-docs -Ddocs=true && ninja -C build-docs docs/valadoc` (same pattern as webview2-gtk; no Android cross required).

### Java

- **🔷** Consumers must copy `lib/host/java/org/roojs/webkitgtk/android/*.java` into the app Java tree (same APK ClassLoader as the `.so`).
- **🔷** Helper: `scripts/android/install-webview-java.sh <java-src-root>`.
- **✔️** Browser Pixiewood build already calls this.

### Pixiewood note

- **ℹ️** APK / `meson install` under Pixiewood often stages **runtime `.so` only** (devel `.pc` / headers / VAPI may not land in `.pixiewood/root`). Prefer **subproject + override_dependency** for compiling consumers.

## Shipped layout

```
lib/webkitgtkandroid/     → Vala sources in libwebkitgtk-android-1
lib/host/*.c + java/      → JNI + Java (Java not in the .so)
vapi/webkitgtk-android-1.vapi
examples/browser/         → links library (+ host-a11y.vala for demo dump)
scripts/android/install-webview-java.sh
meson.build               → library always (except hello-only); pkg.generate
```

Verify browser APK:

- `libwebkitgtk-android-browser.so`
- `libwebkitgtk-android-1.so`
